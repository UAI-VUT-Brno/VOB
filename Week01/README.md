# VOB — Week 1, code snippets

Every folder is a complete console project. Run it with:

```
cd Oop01.01.HelloWorld
dotnet run
```

| project | guide section | what it shows |
|---|---|---|
| `Oop01.01.HelloWorld` | 5.3 | top-level statements written out in full |
| `Oop01.02.ClassAndMethods` | 5.2 | fields, methods, static |
| `Oop01.03.PrintBoth` | 5.3 | why nothing runs unless `Main` calls it |
| `Oop01.04.CarFieldAndMethod` | 6.1 | a class with a field and a method |
| `Oop01.05.ThreeCarObjects` | 6.2 | three objects, each with its own state |
| `Oop01.06.PackageVolume` | 6.3 | a method returning a value, and one taking an object |

Projects 03–06 carry the tasks from the guide as comments in `Program.cs`.
