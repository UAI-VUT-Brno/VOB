# VOB — Week 3, exercise projects

Every folder is a complete .NET 10 console application:

```
cd Oop03.01.Inheritance
dotnet run
```

| project | guide block | topic |
|---|---|---|
| `Oop03.01.Inheritance` | 1.1 | write a base class and two derived ones |
| `Oop03.02.InheritanceRefactor` | 1.2 | three copy-pasted classes → one base class |
| `Oop03.03.Interfaces` | 2.1 | two interfaces, one class implementing both |
| `Oop03.04.InterfaceOrParent` | 2.2 | when an interface, when a parent class |
| `Oop03.05.Polymorphism` | 3.1 | `List<IPowerConsumer>`, one loop, several kinds |
| `Oop03.06.PolymorphismRefactor` | 3.2 | enum + switch → an interface and classes |
| `Oop03.07.Abstraction` | 4.1 | a thermometer that does not care which display it uses |
| `Oop03.08.AbstractionRefactor` | 4.2 | an alarm hard-wired to e-mail → an interface |
| `Oop03.09.Encapsulation` | 5 | public fields → a tank that guards itself |
| `Oop03.10.DataTypes` | 6 | overflow, binary fractions, division, casts, `var` |
| `Oop03.11.ValueVsReference` | 7.1 | the same code as a struct and as a class |
| `Oop03.12.ReferenceInside` | 7.2 | a shared list hiding inside a copied object |

Block 8 of the guide needs no code — it is paper and pencil.
