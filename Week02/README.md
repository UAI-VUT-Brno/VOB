# VOB — Week 2, clean code

| item | guide block | what it is |
|---|---|---|
| `CleanCodeRules/` | 2 | the rule collection, six topics, BAD / BETTER snippets |
| `Oop02.01.DirtyCode` | 3 | a running project that breaks almost every one of them |
| `Oop02.02.PvZLikeDemo` | 4 | the game, WinForms — Windows only |
| `Oop02.03.PvZLikeConsole` | 4 | the same game in the terminal — runs anywhere |

`CleanCodeRules/` holds fragments, not programs. Read them, do not build them.

Everything else is a complete .NET 10 project:

```
cd Oop02.01.DirtyCode
dotnet run
```

The two game folders are two variants of the same game with the same rules,
the same structure and the same bugs — take whichever your machine runs.
