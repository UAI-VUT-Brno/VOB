# VOB — Week 06

Most of the classes are yours to write; the guide says what they do.

| Project | Part | What it is |
|---|---|---|
| Oop06.01.LabDevices | 1 | devices of a measuring lab: an oscilloscope and a power supply |
| Oop06.02.ProductionLine | 2 | a press, a robot and a conveyor started in one loop |
| Oop06.03.TestBench | 3 | sensors of a test bench that each write a report line |
| Oop06.04.ToolCrib | 4 | power tools prepared for the shift |
| Oop06.05.Gauge | 5 | a compressor panel that shows whole numbers only (top-level statements, no classes) |

Open a project folder in VS Code and run it with `dotnet run`.
